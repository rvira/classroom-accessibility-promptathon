# Signal research appendix

Prepared 2026-11-14. Team citation hub for the prototype, slides and pitch.

- [Annotated core sources](sources.md): citation details, findings, applicability and limitations.
- [Evidence-to-design map and pitch wording](design-evidence.md): which decisions the sources inform.
- [Complete source-link inventory](source-inventory.md): all external links cited in our research notes, including competitors, implementation tools and event context.

Use source IDs such as [S1] in slide notes and link to the original publication. These IDs are local to this appendix. Product documentation is not research evidence; population statistics are not evidence that Signal works. Core source summaries paraphrase public guidance and study abstracts; they are not a systematic review or full-text methodological appraisal.

Describe Signal as **research-informed**, not clinically proven, ADHD treatment, or certified accessible. We have not conducted a Signal user study. Our proposed acceptance checks are not completed experimental results.

Maintenance: when adding a source, record author/organization, title, year when known, canonical URL, evidence type, finding, design implication, and limitation. Preserve denominators and study populations. Record actual user feedback and tests separately, with consent and no private student data in this public repository. Do not upload copyrighted full papers or private event documents without permission.
